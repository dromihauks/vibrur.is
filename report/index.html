Your log file ~30 sec

The game writes a log while you play. Attaching it is the most useful thing you can do.

  1. Click Choose file below.
  2. Paste this into the address bar and press Enter:
    %LOCALAPPDATA%\BetterTogether\Saved\Logs
  3. Pick BetterTogether.log. If the game crashed, add the files in ...\Saved\Crashes too.
Screenshots are welcome too. Up to 10 MB in total. Bigger files can go to dromi@vibrur.is.
